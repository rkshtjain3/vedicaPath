# Jagannatha Hora (JHora) Benchmark Validation Framework

## Overview
This document describes the benchmark validation system comparing Personal Vedic Astrology & Numerology Analyzer outputs against external reference data generated by Jagannatha Hora (JHora 8.0+).

The architecture ensures complete astronomical and mathematical transparency without employing any LLMs, AI, or arbitrary logic.

---

## Benchmark Cases (12 Scenarios)
The initial dataset resides in `validation/benchmark-data/jhora/jhora-dataset/`:

1. **JHORA-001**: Normal Indian Birth (New Delhi)
2. **JHORA-002**: Birth Close to Midnight (23:59:45)
3. **JHORA-003**: Lagna Boundary (00°01' Sign transition)
4. **JHORA-004**: Planet Close to Sign Boundary (29°59')
5. **JHORA-005**: Nakshatra Boundary (13°20' Pada boundary)
6. **JHORA-006**: Dasha Boundary (Mahadasha transition)
7. **JHORA-007**: DST Ambiguous Local Time (Fall Back transition)
8. **JHORA-008**: DST Non-Existent Local Time (Spring Forward gap)
9. **JHORA-009**: Foreign Location (London, UK)
10. **JHORA-010**: High Latitude Location (Oslo, Norway > 55°N)
11. **JHORA-011**: Historical Birth (1890 Pre-LMT Standard)
12. **JHORA-012**: Exaltation/Debilitation Boundary Scenario (Peak Sun Exaltation 10° Aries)

---

## Policy on Reference Values
- Reference values are **never fabricated**.
- Unentered reference fields default to `NOT_VALIDATED`.
- Partial reference data entries (e.g. entering only planetary longitudes) evaluate entered fields without failing missing fields.

## Running Benchmarks
- Web Dashboard: Navigating to `http://localhost:3000/benchmark`.
- API Endpoint: `GET /api/benchmarks/jhora` and `POST /api/benchmarks/jhora/[id]`.
- Automated Test Suite: `pnpm test`.
